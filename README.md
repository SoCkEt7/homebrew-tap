# Homebrew Tap for @SoCkEt7

Official Homebrew tap for high-performance developer tools and security software engineered by [Antonin Nivoche (@SoCkEt7)](https://github.com/SoCkEt7).

## Installation

```bash
# Add the tap
brew tap socket7/tap

# Install Livediff (Live terminal diffs while files change)
brew install socket7/tap/livediff
```

Or install in a single command:

```bash
brew install socket7/tap/livediff
```
